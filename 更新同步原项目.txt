# 日常开发 + 同步上游（fork 工作流）

## 布局
- origin   = 自己的 fork（https://github.com/lwwwray/Microsoft-Rewards-Script）
- upstream = 作者 chiihero 的仓库（同步来源）
- main          = v3 线，跟踪 origin/main
- v4-serverchan = v4 线，跟踪 origin/v4-serverchan

## 日常开发（改代码 → 推送自己的 fork）
    git add -A
    git commit -m "说明"
    git push          # 跟踪已配好，无参数即推自己的 fork（origin）

## 拉取作者的同步
v3（main 分支上执行）：
    git fetch upstream
    git merge upstream/main
    # 若有冲突：解决后 git add -A && git commit

v4（v4-serverchan 分支上执行）：
    git fetch upstream
    git merge upstream/V4-china
    # 若有冲突：解决后 git add -A && git commit

同步完再 git push 即可把合并结果推回自己的 fork。

## 常用查看命令
    git branch -vv        # 每个分支的跟踪关系/领先落后
    git status            # 当前分支状态
    git remote -v         # 已配置的远程
